## 1. Situation

A custom checkout implementation could not meet Alpha Bank's technical requirements using the existing configuration.

## 2. Objective

Clarify the bank's requirements, obtain the necessary technical access and translate the findings into actionable work for the development team.

## 3. What I did

- Contacted the bank's technical department.
- Obtained access to the relevant API documentation and credentials process.
- Investigated the existing limitation.
- Documented the findings and proposed implementation requirements.
- Regression-tested the checkout and related workflows after implementation.
- Configured supporting SMTP and webhook connections where required.

## 4. Result

The banking integration was delivered and verified through an operational customer checkout journey.

## Recruiter takeaway

> Coordinated directly with Alpha Bank's technical team to obtain API requirements, translated them into developer-ready documentation and regression-tested the completed checkout integration through production-relevant workflows.
